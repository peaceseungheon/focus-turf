# 스택 지침

이 문서는 프로젝트 스택별 지침 문서의 현재 상태를 안내한다. 스택 확정 시 지침 문서를 만드는 절차와 에이전트가 지켜야 할 행동도 함께 정의한다.

## 현재 상태

- 2026-08-31 모바일 앱 스택 **React Native + TypeScript 확정** — 지침 문서: [react-native.md](react-native.md)
- 백엔드 스택은 미정이다. 스택이 확정될 때마다 이 목록에 추가한다.

## 확정 시 절차

스택(언어 또는 프레임워크)이 확정되면 다음 5단계를 순서대로 실행한다.

1. `_template.md` 를 복사해 `stack/<언어-또는-프레임워크>.md` 생성 (예: `typescript.md`)
2. 문서의 모든 placeholder 를 채움
3. AGENTS.md 지침 맵에 한 줄 추가
4. 이 README 의 상태를 갱신
5. 이후 해당 언어 작업은 반드시 이 문서를 먼저 읽음

## 에이전트 지시

- 스택 지침이 없는 언어로 작업을 시작해야 할 때는 코드를 먼저 쓰지 않는다. 사용자에게 이 양식으로 지침 문서를 먼저 만들 것을 제안한다.
- 제안이 받아들여지면 위 `확정 시 절차`를 그대로 따라 문서를 만들고, 그다음부터는 그 문서를 따른다.
