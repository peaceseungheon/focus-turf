# 스택 지침 양식

이 문서는 언어·프레임워크별 스택 지침의 양식이다. 복사한 뒤 각 항목의 안내 문장에 맞춰 칸을 채우고, 채우고 나면 안내 문장은 지운다.

## 개요

이 스택을 프로젝트 어디에 쓰는지, 이 문서가 다루는 범위를 짧게 적는다.

<placeholder>

## 버전·도구체인

채택한 언어·런타임·패키지 매니저와 각 버전, 버전 고정 수단을 적는다.

<placeholder>

## 프로젝트 구조 규약

소스·테스트·설정 디렉토리의 위치와 신규 파일 배치 규칙을 적는다.

<placeholder>

## 네이밍 표기 규칙

파일, 디렉토리, 타입·클래스, 함수, 변수, 상수의 표기법을 항목별로 적는다.

<placeholder>

## 포맷·린트 도구와 설정

포맷터와 린터의 이름, 설정 파일 경로, 주요 규칙, 실행 명령을 적는다.

<placeholder>

## 테스트 프레임워크와 실행 명령

테스트 프레임워크, 테스트 파일의 위치와 네이밍 규칙, 전체·단일 실행 명령을 적는다.

<placeholder>

## 빌드·실행 명령

개발 실행, 빌드, 프로덕션 실행 명령과 각 명령의 사전 조건을 적는다.

<placeholder>

## 의존성 관리 규칙

의존성 추가·제거·업데이트 절차와 금지 사항을 적는다.

<placeholder>

## 언어 특화 안티패턴

이 언어·프레임워크에서 자주 나는 실수와 금지할 패턴을 목록으로 적는다.
