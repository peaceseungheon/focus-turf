## 2. 프로젝트 개요 (Overview)

- **프로젝트명:** Focus Turf (가칭)
- **서비스 정의:** 유저가 특정 장소(도서관, 카페, 집 등)에서 머물며 집중(공부, 업무, 독서)한 시간을 지도의 '영토'로 환산하여 점령하고 경쟁하는 공간 몰입형 겜미피케이션(Gamification) 서비스
- **타겟 유저:** 국내 공시생, 대학생, 개발자, 프릴랜서 등 특정 장소에서 정기적으로 장시간 집중이 필요한 유저
- **핵심 가치:** 정적인 집중 시간에 게임적 경쟁 요소를 부여하여 지속적인 동기부여를 제공하고, 내가 자주 가는 단골 공간을 내 영토로 선포하는 재미 제공
- **핵심 루프:**

```
장소 도착 → 위치 검증 후 타이머 가동 → 몰입 포인트 축적
→ 타일 점령 / 영주 획득 → 감쇠 시스템이 재방문 유도 → 경쟁·랭킹으로 동기 보강
```

## 4. 유저 시나리오

### 시나리오 A. 공시생 (핵심 타겟)

1. 매일 아침 집 앞 스터디카페에 도착한 유저는 앱을 켜고 집중 타이머를 가동한다.
2. 노멀 모드로 3시간 집중. 세션 종료 후 해당 타일에 1,800점이 반영되고, 스터디카페 타일의 영주가 되어 타일이 내 색으로 칠해진다.
3. 다음 날 결석하면 감쇠가 시작된다는 것을 인지하고, 같은 타일에서 다른 수험생과 영주를 다투게 된다. 이 경쟁이 매일 출석하는 동기가 된다.

### 시나리오 B. 프리랜서 개발자

1. 노트북을 들고 단골 카페를 옮겨 다니는 유저. 카페마다 이미 다른 사람의 영토가 칠해져 있다.
2. 하드코어 모드로 집중해 1.2배 포인트를 축적하며 기존 영주를 추격한다.
3. 마이페이지에서 주간 집중 시간 통계와 내 영토 목록을 확인하며 루틴을 관리한다.

## 5. 용어 정의 (Glossary)

| 용어 | 정의 |
| --- | --- |
| 타일 (Tile) | 지도를 분할하는 정육각형 격자 단위. 점령의 최소 단위 |
| 몰입 포인트 (Focus Score) | 집중 세션으로 획득하는 점수. 타일마다 개별 누적 |
| 영주 (Master) | 해당 타일에서 최고 누적 보유 스코어를 가진 유저. 타일은 영주의 퍼스널 컬러로 표시 |
| 무주지 (Neutral) | 보유 스코어가 0이거나 영주가 없는 타일. 누구나 점령 가능 |
| 감쇠 (Decay) | 무활동 타일의 보유 스코어를 매일 일정 비율 감소시키는 시스템 |
| 방어 (Defend) | 감쇠가 시작되지 않도록 해당 타일에서 집중 활동을 유지하는 행위. 별도의 방어 쿨타임 개념은 없음 (v0.1의 모호한 표현 정리) |
| 보호 구역 (Private Zone) | 프라이버시 보호를 위해 점령 시스템에서 제외되는 타일 (§9) |
| 세션 (Session) | 타이머 가동 시작부터 종료까지의 집중 단위 |
| 히스테리시스 (Hysteresis) | 타일 경계 인근에서 GPS 오차로 인한 잦은 타일 전환을 막는 판정 지연 장치 |

## 6. 핵심 서비스 메커니즘 (Core Mechanics)

> 이 절의 수치는 **초기 가설**이며, 베타 기간 튜닝 대상이다(§18 참조).

### ① 영토 격자화 (Grid Unit)

- 지도 분할 및 서비스 제공 범위는 **대한민국 국내 영역으로 한정**한다. 지도 데이터·법령 준수·운영 정책 모두 국내 기준을 적용한다.
- **타일 규격(가설):** 변 길이 약 25m (전체 폭 약 50m, 면적 약 1,600㎡ ≈ 도서관 열람실 1개 규모)
- **육각형 채택 사유:** 이웃 타일 6방향 등거리 배치로 영토 형태가 자연스럽고, 중심-경계 거리가 일정해 경계 판정이 사각형보다 유리.
- 격자 좌표 체계는 기술 검토 과제로 한다(예: Uber H3, §12).

### ② 영토 점령 및 영주(Master) 시스템

- **포인트 산출(가설):** 노멀 모드 분당 10점, 하드코어 모드 분당 12점(1.2배).
- **영주 판정:** 해당 타일에서 보유 스코어가 가장 높은 유저가 영주. 보유 스코어는 획득 누적치에서 감쇠분을 차감한 값.
- **최소 점령 문턱(가설):** 보유 스코어 100점(노멀 기준 10분 상당) 이상부터 영주 성립. 미달 시 해당 타일 점령으로 인정하지 않는다.
- **동점 처리:** 먼저 해당 스코어에 도달한 유저가 영주를 유지한다(선점 우선).
- **점령 타일 수 상한:** 초기에는 제한 없음. 상한 도입 여부는 오픈 결정사항(§18).
- **시각화:** 영주의 타일은 영주의 퍼스널 컬러로 칠해짐.

### ③ 영토 풍화 및 자동 리셋 (Decay System)

- 목적: 특정 유저의 장기 독점 방지, 신규 유저 유입 경로 확보.
- **판정 시점:** 매일 04:00 (KST).
- **감쇠 조건:** 판정 시점 직전 24시간 동안 해당 타일에서 획득한 포인트가 0인 경우, 해당 타일 보유 스코어에서 15%(가설) 감소.
- 보유 스코어가 최소 점령 문턱(100점) 미만으로 떨어지면 영주 지위 상실, 0에 도달하면 무주지(Neutral) 전환.
- **참고 계산:** 이탈한 영주의 스코어는 0.85^n 감쇠로 14일 후 약 10% 수준까지 소멸 → 자연스러운 영토 교체 주기(약 2주)가 형성됨.
- 타일 상세 팝업에는 "방어 남은 시간" 대신 **"감쇠까지 남은 시간"**(직전 활동부터 24시간까지의 잔여 시간)을 표기한다. (v0.1의 '방어' 개념 정리, §5 참조)

### ④ 부정 이용 및 이동 감지 (Cheat Prevention)

**이동 중 점령 차단**

- 이동 속도가 10km/h(가설) 이상으로 3분 이상 지속 감지되면 타이머 자동 일시정지.
- 타이머 시작 시점 타일 영역(지오펜스)을 벗어나면 타이머 자동 일시정지.

**GPS 스푸핑(목업 위치) 대응 — v0.2 신설**

- Android mock location 플래그, iOS 시뮬레이터/탈옥·루팅 단말 감지 시 세션 무효.
- 물리적으로 불가능한 위치 급점프(예: 직전 위치와 수 분 내 수 km 이동) 감지 시 세션 무효.
- 사후 검증: 동일 계정의 비정상 패턴(동시간대 다수 도시 활동 등) 감지 시 포인트 삭감/제재.

**실내 위치 오차 대응 — v0.2 신설**

- 도서관·카페 등 핵심 공간은 GPS 오차가 큰 환경이므로, 다음을 요구사항으로 한다.
  - Wi-Fi 기반 보조 위치 활용.
  - 지오펜스 판정에 허용 오차 반경(가설: 20m) 적용.
  - 히스테리시스: 경계 인근에서 일정 시간(가설: 60초) 이상 체류해야 타일 전환을 판정. 경계 흔들림으로 인한 오점령·오일시정지 방지.

## 7. 집중 타이머 모드 정책 명세

| 구분 | 모드명 | 작동 방식 | 비고 |
| ----- | ------- | ---------- | ----- |
| 기본값 (Default) | 노멀 모드 (Normal Mode) | 타이머 가동 중 타 앱(인강, 음악, 메모 등) 자유로운 사용 허용. 위치 검증만 수행: 지정된 타일 영역 이탈 또는 이동 속도 감지 시 타이머 중지 | 일상적인 멀티태스킹 보장 |
| 선택 옵션 (Optional) | 하드코어 모드 (Hardcore Mode) | 본 앱이 **포그라운드를 벗어나는 것**(홈 화면 전환, 타 앱 실행)을 감지하면 즉시 세션 실패 처리. 몰입 포인트 1.2배 지급 | 고강도 집중 희망 유저용 |

### 하드코어 모드 기술 전제 (v0.2 수정)

- OS 정책상 **백그라운드에서의 타 앱 사용 추적은 불가능**하다(iOS/Android 공통). 따라서 감지 기준은 "본 앱이 포그라운드를 벗어남"으로 한정하며, 화면 전환·타 앱 실행은 앱이 백그라운드로 내려가는 시점에 감지된다.
- **예외 처리(가설, 정책 확정 필요 §18):** 전화 수신, 자동 화면 꺼짐/단말 잠금, 제어센터·알림센터 일시 노출은 즉시 실패 대신 3분 유예 후 복귀하지 않으면 실패 처리.

### 세션 공통 정책 (v0.2 신설)

- **최소 인정 단위:** 세션 1분 미만은 점수 미부여.
- **세션 정산 시점:** 세션 종료 시점에 즉시 반영. 타이머 가동 중인 유저의 실시간 스코어는 타인에게 비공개하며, 해당 타일에 "집중 중" 상태만 표시한다.
- **백그라운드 연속성:** 전화 수신, 화면 꺼짐, 백그라운드 전환 시에도 타이머 데이터와 위치 검증이 유지되어야 함(§11).

## 9. 프라이버시 및 사생활 보호 정책 (v0.2 신설)

### 보호 구역 (Private Zone) 정책

- 유저가 지정한 보호 구역 타일은 **점령 시스템에서 완전 제외**된다.
  - 해당 타일에서의 집중 시간·포인트는 **개인 통계에만 반영**되고, 영주 판정·지도 표시·랭킹에서는 제외된다.
  - 지도상 해당 타일은 해당 유저에게만 보호 구역으로 표시되고, 타인에게는 일반 무주지로 표시될 수 있다.
- **사유:** 집에서 집중한 기록이 집 타일 점령으로 이어지면 역설적으로 거주지가 노출된다. 점령 자체를 제외하는 것이 프라이버시상 안전하다.
- 검토 후 기각한 대안: "점령은 허용하되 익명 색상으로 표시" — 익명 처리는 우회적 추정(이웃 타일 소유 패턴 등)으로 노출될 여지가 있어 기각. 재검토 여지는 §18.

### 공통 프라이버시 원칙

- 타인에게 노출되는 정보는 닉네임·퍼스널 컬러·타일 점유 사실으로 한정. 실명·연락처 미수집.
- 위치 이력은 서버 저장 시 좌표 라운딩 등 최소화 처리를 검토한다(§14).
- 닉네임 기반 익명성 보장 및 부적절 닉네임 필터링(§13).

## 10. 신규 유저 및 리텐션 설계 (v0.2 신설)

### 콜드스타트 대응

- **첫 영토 이벤트:** 온보딩 직후 첫 세션(10분) 완료 시, 주변 무주지 1타일을 즉시 점령시켜 첫 성공 경험을 만든다.
- **목표 타일 우선 노출:** 신규 유저에게는 무주지·감쇠 진행 타일을 우선적으로 지도에 노출하여 "뺏을 수 있는 땅"이 보이게 한다.
- **신규 유저 vs 기존 영주 격차:** 이탈 영주의 스코어는 약 2주 내 90% 소멸(§6-③)하므로, 활동 중인 신규 유저가 방치된 영토를 따라잡는 데 필요한 예상 기간은 약 1~2주. 베타에서 실측 검증한다.

### 솔로 유저 콘텐츠 (경쟁자가 없는 지역 대응)

- 주변에 경쟁자가 없어도 개인 통계(누적 시간, 연속 출석일)와 최장 기록 경신으로 루프가 유지되도록 한다(P2 업적과 연계).
- 인구 밀도 낮은 지역은 무주지 비율이 높아 점령 자체의 성취감으로 초기 재미를 유지하는 구조.

### 재방문 장치

- 감쇠 시스템 자체가 데일리 재방문 유도 장치(§6-③).
- P1 알림(감쇠 임박, 영주 방어전) 추가 시 리텐션 강화 예정.

## 11. 비기능적 요구사항 및 정책 (Non-Functional Requirements)

- **실내 위치 정확도 (v0.2 신설, 최우선 리스크):** 핵심 이용 공간(도서관, 카페, 실내 학원)이 GPS 오차가 가장 큰 환경임을 전제하고, §6-④의 보조 위치·허용 오차·히스테리시스 요구사항을 만족해야 한다. 이 요구사항 미충족 시 서비스 가치 자체가 훼손되므로 개발 초기 기술 검증(Spike) 항목으로 지정한다.
- **배터리 효율:** 집중 세션 중 위치 샘플링 주기(가설: 15초)를 최적화하고, 세션 외 구간에서는 능동적 위치 수집을 하지 않는다.
- **안정적인 백그라운드 처리:** 집중 타이머 작동 중 전화 수신, 화면 꺼짐, 백그라운드 전환 시에도 타이머 데이터와 위치 검증이 끊기지 않아야 함. 타이머 상태는 로컬에 저장하여 앱 강제 종료 후에도 무결성이 보장되어야 한다.
- **위치 권한 정책 (v0.2 수정):** 필수 권한을 '사용 중 위치'로 한정하고, 백그라운드 위치는 화면 꺼짐 상태의 타이머 무결성 보장용 선택 권한으로 안내한다. 이는 앱스토어 심사 정책(백그라운드 위치 필수 요구 시 리젝 사유) 대응이며, 선택 권한 미동의 시에도 서비스 핵심 루프가 동작해야 한다.
- **직관적인 UX/UI:** 지도 중심 화면 구성. 내 땅/타인 땅/무주지/보호 구역의 명확한 컬러 대비 체계. 퍼스널 컬러 중복 시에도 식별 가능하도록 패턴/농도 변주를 고려하고 색약 유저 대응을 포함한다.

## 13. 운영 정책 (v0.2 신설)

- **닉네임 정책:** 부적절 표현(비속어, 혐오, 광고성) 자동 필터링 + 수동 검수.
- **신고/차단:** 타인 프로필·타일 상태에서 신고 가능. P0에는 최소 신고 접수 채널(고객센터)만 제공하고 앱 내 신고 UI는 P1~P2.
- **부정 이용 제재:** §6-④ 감지 시 단계적 제재(세션 무효 → 포인트 삭감 → 이용 정지).
- **영토 분쟁:** 감쇠 규칙이 분쟁을 구조적으로 해소(점수 우위 명확). 예외 처리는 운영 정책으로 대응하며 분쟁 조정 절차를 사전에 정의한다.
- **커뮤니티 가이드라인:** 직접 메시지·채팅 기능은 계획에 없음(도입 시 별도 가이드라인 수립). 실물 추적·저격 우려가 있는 기능(실시간 위치 공유 등)은 도입 금지 원칙.
